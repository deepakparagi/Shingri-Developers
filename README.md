## 📌 About

Monte Web serves as the primary digital portal for Shingri Developers. Breaking away from generic property listings, this application treats real estate as a premium digital experience. 

The UI is a masterclass in Minimal Luxury, utilizing an aesthetic palette of Monte Beige and Gold. Every element is meticulously crafted to provide a high-end feel, featuring dynamic parallax carousels, full-screen glassmorphic overlays, and physics-based interactions that collectively establish unparalleled digital authority.

## ✨ Key Features

| Feature | Description |
|:---|:---|
| 🎨 **Minimal Luxury UI** | A high-contrast aesthetic utilizing bespoke Monte Beige, Gold, and Charcoal color palettes |
| 🎬 **The Hero Experience** | Dynamic, full-bleed parallax carousels with 3D depth and masked text reveal animations |
| 🔍 **Glassmorphic Navigation** | Sticky headers and full-screen `backdrop-blur-3xl` search overlays |
| 🌊 **Kinetic Interactions** | Floating project cards, interactive statistics, and sliding underlines powered by Framer Motion |
| ⚡ **Next-Gen Performance** | Built on Next.js 16 and React 19 for instantaneous routing and server-side optimization |
| 📱 **Responsive Fluidity** | Seamless scaling across all devices ensuring the luxury feel remains intact on mobile |

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 22.x
- **npm** or **yarn**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/Shingri-Developers.git

# 2. Navigate into the project
cd Shingri-Developers

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:3000`

## 📁 Project Structure

```
Shingri-Developers/
├── app/                    # Next.js App Router (Pages, Layouts, global CSS)
```
